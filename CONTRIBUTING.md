Contributing
---

Thank you for contributing!

**doki-theme-jetbrains** is one part of the Doki Theme ecosystem. It is a
project relying on other doki theme projects. So for starters, take a look
at [Development Setup](./md_docs/DEV_SETUP.md)
to setup your doki-theme-jetbrains project.

## Ways to contribute

- Improve the automation workflow for constructing the doki-theme-jetbrains plugin.
  - See [Development Setup](./md_docs/DEV_SETUP.md) for automation process.
- Locate UI colors not following a doki theme.
- Develop new features.
- Create a new color theme of an existing doki theme. See [New Color Theme](./md_docs/NEW_COLOR_THEME.md)
